# Матрица "таблица -> владелец данных -> бизнес-сценарий"

| Таблица | Владелец данных | Бизнес-сценарии |
|---|---|---|
| `users` | Пользователь / администратор платформы | Авторизация, роли |
| `venues` | Организатор | Создание мероприятия |
| `venue_seats` | Организатор | Настройка схемы зала |
| `events` | Организатор | Создание, публикация, отмена, завершение |
| `ticket_categories` | Организатор | Настройка цены и квоты |
| `event_seats` | Организатор | Привязка мест к мероприятию |
| `orders` | Покупатель + платформа | Бронирование, оплата, возврат |
| `order_items` | Покупатель + платформа | Состав заказа |
| `tickets` | Платформа | Выпуск, QR, проход, аннулирование |
| `payments` | Платформа / внешний эквайер | Статус оплаты |
| `refunds` | Платформа / внешний эквайер | Возврат отдельного билета |
| `ticket_scans` | Контролёр / платформа | Проверка входа и аудит |
